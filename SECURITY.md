# Politique de sécurité

## Versions prises en charge

Ce projet de démonstration maintient uniquement la version présente sur la branche
`main`.

## Signaler une vulnérabilité

N'ouvrez pas d'issue publique contenant une vulnérabilité ou un secret. Utilisez la
fonction **Report a vulnerability** dans l'onglet Security du dépôt GitHub. Décrivez
le risque, les étapes de reproduction et, si possible, une correction proposée.

## Périmètre

Le fichier Docker Compose est conçu pour un environnement local. Il ne constitue
pas une configuration de production exposée à Internet.
